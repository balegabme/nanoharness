# NanoHarness

Minimal, opinionated coding harness whose twin obsessions are token efficiency
and self-documentation: every source file links to the md doc that explains it,
so any agent (or the user) can navigate the harness and modify it safely.

Status: planning complete, build in progress. See plan.md and docs/.

## Development

Requires Node 20+ and pnpm.

    pnpm install
    pnpm typecheck
    pnpm lint
    pnpm test
